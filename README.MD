# Travel Spend Analytics Dashboard

An interactive Streamlit dashboard for exploring travel expenditure by travel purpose, destination, and party size.

## Project Overview

This project uses Python to analyse travel spending patterns, compare business and leisure travel costs, and explore relationships between expenditure and destination-level economic indicators.

## Features

- Interactive filters for travel purpose and destination
- Travel expenditure analysis
- Business versus leisure spending comparisons
- Statistical tests and effect size analysis
- Destination-level economic context
- Interactive Plotly visualisations
- Downloadable filtered datasets

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- SciPy

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Activate your virtual environment.
4. Install the required packages.
5. Run the dashboard:
